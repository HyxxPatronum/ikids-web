# Account、多设备同步与移动端支持

Type: feature
Status: pending

## 背景

学生端将先迁移为易懂的 React + TypeScript 前端，并移除当前 Cloudflare D1、R2 和 Worker 代码。第一阶段不实现登录和远程同步，但正式产品仍需要 Account、多设备学习进度同步和移动端适配，因此这些能力不能在重构中被当作永久取消。

## 范围

- 支持稳定的 Account 登录与退出。
- 同一 Account 可在手机、平板和桌面端读取学习进度。
- 同步课程完成度、练习答案、模块得分和录音元数据。
- 明确离线学习后的合并规则，避免旧设备覆盖新进度。
- 学生端适配移动端触控、窄屏布局、音频播放和录音权限。
- Account 与同步后端和学生前端分离，学生前端只依赖稳定的数据契约。

## 暂不实现

- 当前 React 前端迁移阶段不选择身份供应商。
- 当前阶段不建立远程数据库或云端录音存储。
- 当前阶段不把后台管理系统与学生产品打包在一起。

## 实现前决策

1. 身份方式：邮箱、第三方登录或学校统一身份。
2. 同步后端的部署位置和数据库类型。
3. 离线进度的版本、冲突和合并规则。
4. 录音是只同步元数据，还是同步原始音频。
5. Account 数据与独立内容后台之间是否共享用户体系。

## 完成标准

- 两台设备登录同一 Account 后可以看到一致的课程进度。
- 离线修改在恢复网络后不会静默丢失较新的记录。
- 未登录用户仍可使用明确限定的本地学习模式。
- 手机端完成课程、播放音频和录音的主流程可用。
- 学生前端不包含供应商专属数据库或对象存储代码。
